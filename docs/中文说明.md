# CodeGate 中文说明

> 写码前先过闸——没有设计、计划、失败复现和新鲜证据，不许说做完了。

## 1. 定位

CodeGate 是给 **Codex / OpenCode 等编码 Agent** 用的工程纪律套件。

- ✅ 功能、重构、修 bug、宣称完成  
- ❌ 代币审计、行情、meme 扫链（那是 TradeGate，独立仓库）  
- ❌ 拷贝包装 obra/superpowers  

## 2. 四道硬闸（加入口共 5 skill）

```text
新需求 ──► design-before-code ──► plan-before-build ──► 实现
                                                              │
bug/回归 ──────────────────────► test-before-fix ───────┘
                                                              │
宣称完成 / commit / PR ────────────────────► verify-before-done
```

| Skill | 硬规则 |
|---|---|
| `design-before-code` | 未批准设计不写生产代码 |
| `plan-before-build` | 无任务清单与验证方式不开干 |
| `test-before-fix` | 无 RED 复现不着陆修复 |
| `verify-before-done` | 无本回合新鲜证据不说完成 |

## 3. 安装

```bash
# 在仓库根目录
bash scripts/install-local.sh
```

然后重启 Codex / OpenCode。

OpenCode 也可手动：

```json
{ "plugin": ["/绝对路径/codegate"] }
```

## 4. 对 Agent 怎么说

- 「先过设计闸再写」  
- 「按 plan-before-build 拆任务」  
- 「这个 bug 走 test-before-fix」  
- 「提交前 verify-before-done」  

## 5. 建议落盘位置

- 设计：`docs/codegate/designs/YYYY-MM-DD-<topic>.md`  
- 计划：`docs/codegate/plans/YYYY-MM-DD-<feature>.md`  

仓库不允许写 docs 时，用对话内卡片代替，但结构不变。

## 6. 安全边界

- 用户明确「跳过设计 / 只要热修」时，记录跳过原因再继续  
- 用户文件 / AGENTS.md 优先级高于本套件  
- 不代替代码审查责任，不保证业务正确，只保证流程上有证据点  

## 7. FAQ

**Q: 和 Superpowers 重复吗？**  
A: 问题域重叠，但 CodeGate 更窄、中文触发优先、双通道安装更简单；需要完整 SDD 生态请用官方 Superpowers。

**Q: 为什么不直接 fork Superpowers？**  
A: 零差 fork 没有安装理由。CodeGate 只保留可执行的硬闸门，不搬运整套上游。
